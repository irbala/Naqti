# Naqti

A camel marketplace concept: browse camels, filter by breed, age, price and location, and list your own camel.

Visit the site: https://irbala.github.io/Naqti/

This is a static design mock-up built with HTML and Tailwind CSS. The links, filters and buttons are not wired up yet.

## Styles

- `tailwind.css` is the compiled Tailwind stylesheet the page uses. It's generated, so don't edit it by hand.
- `styles.css` holds the few custom styles.

If you add new Tailwind classes to `index.html`, rebuild `tailwind.css`:

```
npm install
npm run build:css
```
